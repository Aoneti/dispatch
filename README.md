# Dispatch — расширение Chrome «RSS в X»

Простое локальное расширение для Google Chrome (Manifest V3) на русском языке. Собирает новости из добавленных вами RSS и Atom-лент, позволяет удобно читать статьи, отмечать прочитанные, сохранять на потом и **только по вашему нажатию** генерирует отдельный пост для X с помощью **Google Gemini** (`gemini-3.1-flash-lite`).

Расширение ничего не публикует в X автоматически, не запрашивает доступ к аккаунту X и не использует сторонние серверы, регистрацию, аналитику или телеметрию.

---

## Что умеет расширение

- **Новости** — единая лента статей из всех добавленных RSS/Atom-источников:
  - заголовок, название источника, дата публикации и краткое описание;
  - поиск по заголовку, тексту, автору и источнику;
  - фильтры: все, непрочитанные, прочитанные, сохранённые;
  - сортировка по дате (сначала новые / сначала старые);
  - быстрые действия прямо в списке: прочитать/вернуть в непрочитанные, сохранить, удалить;
  - массовые действия: прочитать всё в текущем представлении, прочитать источник, с отменой;
  - счётчики непрочитанных в общем списке и для каждого источника;
  - кнопка **«Обновить»** для ручного обновления лент (плюс фоновое расписание по умолчанию раз в 30 минут);
  - чтение статьи, переход к оригиналу и кнопка **«Извлечь полный текст»**, если в RSS пришёл только короткий анонс;
  - две независимые кнопки генерации: **«Сгенерировать короткий пост»** и **«Сгенерировать расширенный пост»**.
- **Источники** — управление лентами:
  - добавление RSS 2.0 и Atom по прямой ссылке с предварительной проверкой;
  - настройка названия источника;
  - включение/отключение, обновление отдельной ленты или всех сразу, редактирование и удаление;
  - отображение количества статей, непрочитанных, числа элементов в ленте и времени последней синхронизации;
  - загрузка более старых публикаций, если лента поддерживает пагинацию (RFC 5005);
  - дедупликация статей по GUID, каноническому URL и контрольной сумме текста — повторные обновления не создают дубликаты;
  - поддержка условных HTTP-запросов (`ETag` / `Last-Modified`).
- **Черновики** — независимые посты (каждый черновик соответствует одному формату — короткому или расширенному):
  - текстовый редактор с автосохранением и живым счётчиком символов;
  - кнопки **«Сохранить»**, **«Копировать»**, **«Копировать со ссылкой»** (ссылка на оригинал хранится отдельно и добавляется только по вашему выбору), **«Исходный текст»** (возврат первоначального варианта ИИ) и **«Удалить»**;
  - при повторной генерации уже существующего формата выводится предупреждение о замене (с отдельным акцентом, если черновик редактировался вручную).
- **Настройки** — всё в одном месте:
  - подключение Google Gemini (`gemini-3.1-flash-lite`): ввод своего API-ключа, показать/скрыть, сохранить, удалить, **«Проверить подключение»** (только по клику);
  - тема оформления (светлая, тёмная, системная);
  - переключатель **«Автоматически отмечать прочитанной при открытии»** (включён по умолчанию);
  - очистка старых прочитанных статей (по явному выбору, с сохранением сохранённых и непрочитанных);
  - компактная статистика использования Gemini (запросы, токены, ошибки);
  - экспорт и импорт данных в JSON (API-ключ в экспорт не попадает), очистка локальных данных.

## Модель Google Gemini и бесплатный режим

- Используется только официальный REST API Google Gemini и единственная модель **`gemini-3.1-flash-lite`**:
  `POST https://generativelanguage.googleapis.com/v1beta/models/gemini-3.1-flash-lite:generateContent`
- API-ключ передаётся в заголовке `x-goog-api-key`.
- Другие AI-провайдеры, сторонние модели и платные инструменты (включая Google Search Grounding и Maps Grounding) не подключены.
- Автоматическое переключение моделей отключено. При ошибке `429` бесконечные повторы не выполняются; для временных сбоев используется экспоненциальный backoff с ограничением попыток.
- Генерация запускается **строго вручную** — только после нажатия на кнопку короткого или расширенного поста. Открытие статьи, переключение между новостями, обновление RSS и переход между разделами никогда не вызывают Gemini API.
- Квоты, ограничения и тарифный статус проекта определяет Google. На бесплатном тарифе (Free Tier) Google может использовать содержимое запросов для улучшения своих продуктов. Если ваш проект Google Cloud переведён на платный тариф, условия списания регулирует Google — само расширение не может принудительно изменить биллинг проекта.

## Приватность и безопасность

- **Первый запуск — полностью пустой.** В расширении нет предустановленных RSS-источников, тестовых новостей и демонстрационных черновиков.
- Источники, статьи и черновики хранятся только локально в вашем браузере (IndexedDB + кэш localStorage).
- API-ключ хранится локально (в профиле браузера и `chrome.storage.local`), не синхронизируется через Chrome Sync и никогда не попадает в экспорт JSON, логи и метаданные статей.
- **Прямые запросы без сторонних CORS-прокси.** В Manifest V3 указаны `optional_host_permissions`: разрешение запрашивается только для конкретного домена, когда вы добавляете источник, обновляете его или извлекаете полный текст статьи.
- Текст статьи отправляется только в Google Gemini и только по вашему явному нажатию.
- Все HTML-фрагменты из RSS и веб-страниц очищаются перед отображением (и повторно при чтении из хранилища).
- Нет аккаунтов, сервера, аналитики, телеметрии и рекламы.
- При обновлении со старой версии выполняется безопасная миграция: пользовательские источники, статьи, черновики и правки сохраняются, устаревшие демонстрационные записи удаляются точечно.

## Команды разработки и сборки

Требуется **Node.js 20+**.

```bash
npm install                   # установка зависимостей
npm run dev                   # локальный запуск для разработки
npm run build                 # стандартная production-сборка в папку dist
npm run build:extension       # сборка Chrome Extension (Manifest V3) в папку dist
npm run package:extension     # проверка dist и упаковка в dispatch-extension.zip
```

Сборка `build:extension` использует относительные пути (`base: "./"`), выносит весь JavaScript и CSS в локальные файлы `dist/assets/`, не использует встроенные скрипты (полная совместимость со строгой CSP Manifest V3), не подключает внешние CDN и Google Fonts. Скрипт упаковки работает на Node.js (`jszip`) и не требует сторонней утилиты `zip` — работает одинаково на Windows, macOS и Linux.

Итог сборки:
- папка **`dist/`** — готовое распакованное расширение (`manifest.json`, `index.html`, `background.js`, `assets/`, `icons/`);
- файл **`dispatch-extension.zip`** — готовый ZIP-архив расширения.

Подробная пошаговая инструкция по установке и работе для пользователя Windows находится в файле **[SETUP.md](SETUP.md)**.

## Известные ограничения

- **Фоновое обновление при закрытой панели:** service worker Manifest V3 отмечает наступление расписания значком на иконке, а фактическая загрузка и разбор XML выполняются при открытой боковой панели или сразу при её следующем открытии.
- **Доступ к сайтам:** если сайт защищён от ботов, требует подписку (paywall) или пользователь отклонил запрос разрешения Chrome для домена, получить полный текст не удастся — расширение сохранит фрагмент из RSS и не будет придумывать недостающие факты.
- **Пагинация зависит от издателя:** не все ленты поддерживают загрузку старых публикаций. Если ссылка на архив отсутствует, расширение честно сообщает, что дальше история недоступна.
- **Локальное хранение API-ключа:** защита в профиле браузера слабее серверного хранилища. При доступе посторонних к компьютеру ключ стоит отозвать и перевыпустить в Google AI Studio.
